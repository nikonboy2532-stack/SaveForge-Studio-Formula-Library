# 🎮 SaveForge Studio - Online Formula Library

คลังสูตรโกงเซฟเกมออนไลน์อย่างเป็นทางการสำหรับใช้งานร่วมกับ **SaveForge Studio**
รองรับทั้งเกม **PlayStation 4 (PS4)** และ **PlayStation 3 (PS3)**

---

## 📊 ข้อมูลสรุปคลังสูตร (Catalog Summary)
- **PS4 Formulas:** 212 ไฟล์ (.savepatch)
- **PS3 Formulas:** 1789 ไฟล์ (.savepatch)
- **Personal Formulas:** 0 ไฟล์
- **Security:** มีการลงลายเซ็นดิจิทัล RSA-SHA256 (3072-bit) กำกับทุกไฟล์ใน catalog/formula-catalog.json

---

## 🚀 วิธีการอัปเดตสูตรเข้าโปรแกรม SaveForge Studio
1. เปิดโปรแกรม **SaveForge Studio**
2. ไปที่หน้าต่าง **คลังสูตร (Patch Library)**
3. กดปุ่มสีฟ้า **"อัปเดตคลังออนไลน์" (Update online library)**
4. โปรแกรมจะตรวจสอบและดาวน์โหลดสูตรใหม่ล่าสุดมายังเครื่องของคุณโดยอัตโนมัติ!
